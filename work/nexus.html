Nexus: Agentic Control Plane

An agentic platform that connects the company’s AI agents and gives management one holistic view of all of them, with a single kill switch.

What it is

As the number of production agents grew (voice, chat, lead management, ads, social, escalation), each one ran and reported on its own. Nexus is being built with Claude Code as the layer above them: it connects the agents, shows management what every agent is doing in one place, and puts all of them behind one kill switch. It is work in progress.

Design intent
  1. Connect the agents: every agent registers with Nexus instead of running in isolation.
  2. One holistic view: management sees agent activity and status across the business in one place.
  3. One kill switch: every agent can be stopped from a single control.
  4. Built with Claude Code.
